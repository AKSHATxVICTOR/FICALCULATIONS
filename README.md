## 📌 Project Overview

FI Calculator is a privacy-first web application designed to help investors estimate their Financial Independence (FI) and retirement age using SIP, Lumpsum, and combined portfolio strategies.

The platform provides instant calculations and visual insights while maintaining a simple and transparent user experience.

---

## 🧠 Core Features

### ✔ SIP Calculator
- Monthly SIP input
- Optional annual step-up percentage
- Expected annual return
- Target retirement corpus
- Estimated Financial Independence age

---

### ✔ Lumpsum Calculator
- One-time investment input
- Expected annual return
- Target corpus calculation
- Retirement age estimation

---

### ✔ Portfolio Calculator (SIP + Lumpsum)
- Combined portfolio growth simulation
- Annual compounding logic
- Optional SIP step-up support
- Total invested vs total returns breakdown
- Visual representation using charts

---

## 📊 Visualization

The application displays a clear breakdown of:
- Total Invested Amount
- Estimated Returns

This helps users understand the power of compounding and long-term investment growth.

---

## 🔐 Privacy-First Approach

- No account creation required
- No personal financial data stored
- Real-time calculations only
- Designed with minimal data exposure principles

> “If you don’t need history → don’t use a database.”

---

## 🎯 Objective

To provide a simple, secure, and transparent financial independence estimation tool that allows users to evaluate whether their retirement goals are realistically achievable.
