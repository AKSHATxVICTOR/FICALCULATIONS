# FI Calculator – Financial Independence Planner

FI Calculator is a privacy-first Financial Independence and Retirement Age Calculator designed for Indian investors.  
The application helps users estimate when they can achieve financial independence based on their investments, expected returns, inflation, and retirement goals.

---

## 📌 Problem Statement

In an era of rising inflation, relying on a single income source is often insufficient for long-term financial security and retirement planning. While many individuals invest through SIPs and other instruments, they lack clarity on whether their current investments are sufficient to meet retirement goals.

FI Calculator addresses this gap by providing an easy-to-use tool that analyzes investments and estimates the financial independence age.

---

## 💡 Solution Overview

FI Calculator evaluates user-defined financial inputs and calculates:
- Estimated Financial Independence (FI) age
- Retirement feasibility based on goals
- Impact of compounding and inflation on investments

The platform is designed to be **informational, non-advisory, and privacy-first**.

---

## ✨ Key Features

- Manual financial input system  
- SIP-based investment calculations  
- Financial independence age estimation  
- Goal feasibility analysis  
- Inflation-adjusted projections  
- Scenario comparison capability  
- Visual results and reports  
- Privacy-first design (no data stored by default)  

---

## 🧑‍💻 Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Logic:** Deterministic financial formulas  
- **Deployment:** GitHub Pages  

---

## ⚙️ How It Works

1. User enters financial details such as age, SIP amount, expected return, and target corpus  
2. The system calculates investment growth using compounding logic  
3. The estimated FI age and feasibility result are displayed instantly
